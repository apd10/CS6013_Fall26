Problem formulation

\[ \hat{w} = \underset{\|\hat{w}\|_0 \le k}{\arg\min} \; \bigl\| X\hat{w} - X w \bigr\|_2^2 \]

Problem formulation

This is an NP-hard problem!

Approximations?

Greedy solution space

Let us try to find the first weight to prune which minimizes the goal:

\[ \hat{w} = \underset{\|\hat{w}\|_0 = n-1}{\arg\min} \; \bigl\| X\hat{w} - X w \bigr\|_2^2 \]

Q. How would you do that?

Saliency of a weight

  • Saliency = how much error does it cause if you prune this weight
  • If I remove $w_i$ (the $i$-th weight of $w$), then the error is?
\[ \min_{\hat{w}_{-i}} \; \bigl\| X_{-i}\,\hat{w}_{-i} - X w \bigr\|_2^2 \]

Saliency of a weight

\[ \min_{\hat{w}_{-i}} \; \bigl\| X_{-i}\,\hat{w}_{-i} - X w \bigr\|_2^2 \]

where

\[ \hat{w}_{-i} = \bigl(X_{-i}^\top X_{-i}\bigr)^{-1} X_{-i}^\top X w \]

Algorithm

  • Compute saliency of all the weights
  • Remove the lowest
  • Then repeat

Q. Complexity?

Algorithm

  • Compute saliency: $O(d^3)$
  • # saliencies: $d$
  • Total: $O(d^4)$

Q. What should we do?

How do we analyse the loss function?

Local approximation! The whole field of optimization is based on local understanding of the loss landscape.

How do we approximate locally?

Taylor series approximation

\[ \begin{aligned} \mathcal{L}(w, X) &= \mathcal{L}(w^\star, X) + \nabla\mathcal{L}(w^\star, X)^\top \delta w \\ &\quad + \tfrac{1}{2}\, \delta w^\top \nabla^2\mathcal{L}(w^\star, X)\, \delta w + O(\|\delta w\|_2^3) \end{aligned} \]

where $\delta w = w - w^\star$.

Assumption 1: Quadratic only

\[ \begin{aligned} \mathcal{L}(w, X) &\approx \mathcal{L}(w^\star, X) + \nabla\mathcal{L}(w^\star, X)^\top \delta w \\ &\quad + \tfrac{1}{2}\, \delta w^\top \nabla^2\mathcal{L}(w^\star, X)\, \delta w \end{aligned} \]

Drop the cubic (and higher) remainder.

Assumption 2: Converged model

\[ \mathcal{L}(w, X) \approx \mathcal{L}(w^\star, X) + \tfrac{1}{2}\, \delta w^\top H(w^\star, X)\, \delta w \]

At a minimum, $\nabla\mathcal{L}(w^\star, X) = 0$ — drop the gradient term. ($H = \nabla^2\mathcal{L}$)

Why converged model is a good assumption?

Local geometry far from the minimum is not useful for pruning — start at the converged model.

Error when you move $\delta w$ from a minimum

\[ \begin{aligned} E(\delta w) &:= \mathcal{L}(w, X) - \mathcal{L}(w^\star, X) \\ &= \tfrac{1}{2}\, \delta w^\top H(w^\star, X)\, \delta w \end{aligned} \]

with $H(w^\star, X) = \nabla^2\mathcal{L}(w^\star, X)$.

Saliency$(i)$

\[ \mathrm{Saliency}(i) = \min_{\delta w_i = -w_i} \; E(\delta w) \]

i.e. $w_i$ goes to $0$; the rest of the weights can take any values.

Q. How do we do a constrained minimization?

Lagrange multiplier method

\[ \delta w = \underset{\delta w}{\arg\min} \; T(\delta w, \lambda) = E(\delta w) + \lambda\, e_i^\top (w + \delta w) \]

with $E(\delta w) \approx \tfrac{1}{2}\,\delta w^\top H\,\delta w$.

Stationarity conditions

\[ \frac{\partial T}{\partial \lambda} = 0 \;\Longrightarrow\; \delta w_i = -w_i \]
\[ \frac{\partial T}{\partial (\delta w)} = 0 \;\Longrightarrow\; H\,\delta w + \lambda\, e_i = 0 \]

Solve for $\lambda$

From $H\,\delta w + \lambda e_i = 0$: $\delta w + \lambda\, H^{-1} e_i = 0$.

Match the $i$-th coordinate ($\delta w_i = -w_i$):

\[ -w_i = \lambda\, [H^{-1}]_{ii} \qquad\Longrightarrow\qquad \lambda = \frac{-w_i}{[H^{-1}]_{ii}} \]

Solve for $\delta w$

\[ \delta w = -\lambda\, H^{-1} e_i = \frac{w_i}{[H^{-1}]_{ii}}\, H^{-1} e_i \]

Prefactor is a scalar; $\delta w$ is proportional to the $i$-th column of $H^{-1}$.

Saliency$(i)$ and update

\[ \mathrm{Saliency} = \tfrac{1}{2}\, \frac{w_i^2}{[H^{-1}]_{ii}} \,, \qquad \delta w = \frac{w_i}{[H^{-1}]_{ii}}\, H^{-1} e_i \]

Complexity

  • Dominated by forming / inverting the Hessian: $O(N^3)$
  • $N$ = number of parameters
